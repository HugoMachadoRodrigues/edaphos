# Simulated soil profiles for examples and tests

Returns synthetic soil profile data with the same shape as an ISRIC
WoSIS extract (`kind = "wosis_like"`) or a SoilData Dataverse
bulk-density calibration set (`kind = "soildata_like"`). Every example,
test and vignette in this package runs on these fixtures.

## Usage

``` r
edaphos_example_profiles(
  kind = c("wosis_like", "soildata_like"),
  what = c("profiles", "horizons", "pedon", "all"),
  n = NULL
)
```

## Arguments

- kind:

  Which fixture: `"wosis_like"` (default) or `"soildata_like"`.

- what:

  Which element: `"profiles"` (default), `"horizons"`, `"pedon"` (a
  single deep 9-horizon profile, `wosis_like` only), or `"all"` for the
  whole list including `meta`.

- n:

  Optional row cap, applied after subsetting. `NULL` returns everything.

## Value

A data frame with `attr(, "synthetic") = TRUE`, or the whole fixture
list when `what = "all"`.

## Details

**These are simulated values, not measurements.** They are generated by
`data-raw/make_fixtures.R` from published literature parameters – the
Jackson et al. (1996) tropical-savanna root distribution (\\\beta =
0.972\\), a lognormal surface-SOC concentration with median 25 g/kg, and
a round-numbered bulk-density pedotransfer form. Nothing in them is
fitted to, or sampled from, any real dataset.

Coordinates are a regular lattice inside the Cerrado bounding box rather
than a random scatter, so no fixture point can coincide with a survey
site, and the synthetic origin is obvious on inspection.

The generator is seeded (`set.seed(20260901L)`, recorded in the
fixture's `meta$seed`), so both files are byte-reproducible by
re-running the script.

**What these fixtures cannot do:** reproduce any published metric. Forty
synthetic profiles do not yield the RMSE, coverage or effect-size
figures quoted in the README and the manuscript. Those are reproducible
only from a live fetch, via the scripts in `data-raw/`.

`edaphos` does not bundle or redistribute third-party soil data. Real
profiles are the user's to obtain from the upstream services directly –
ISRIC WoSIS, the SoilData Dataverse, USDA-NRCS – under those services'
own licences, which vary per record.

## References

Jackson RB, Canadell J, Ehleringer JR, Mooney HA, Sala OE, Schulze ED
(1996). A global analysis of root distributions for terrestrial biomes.
*Oecologia* 108:389-411.

## Examples

``` r
prof <- edaphos_example_profiles()
str(prof[, c("profile_id", "soc_topsoil_gkg", "soilgrids_clay")])
#> 'data.frame':    120 obs. of  3 variables:
#>  $ profile_id     : chr  "SYN_001" "SYN_002" "SYN_003" "SYN_004" ...
#>  $ soc_topsoil_gkg: num  29.3 15.7 29.1 33 10 ...
#>  $ soilgrids_clay : num  22.8 51.5 23.7 62.2 51.2 18.3 19.3 17 46.4 52.1 ...

# Horizons of the first profile.
h <- edaphos_example_profiles(what = "horizons")
head(h[h$profile_id == prof$profile_id[1], ])
#>   profile_id   x   y top bottom soc_g_kg depth_mid bd_g_cm3 stock_mg_ha
#> 1    SYN_001 -58 -22   0     27    29.32      13.5       NA          NA
#> 2    SYN_001 -58 -22  27     65    12.50      46.0       NA          NA
#> 3    SYN_001 -58 -22  65     87     6.76      76.0       NA          NA
#> 4    SYN_001 -58 -22  87     98     5.17      92.5       NA          NA
#> 5    SYN_001 -58 -22  98    135     2.50     116.5       NA          NA

# Simulated, and it says so.
attr(prof, "synthetic")
#> [1] TRUE
```
